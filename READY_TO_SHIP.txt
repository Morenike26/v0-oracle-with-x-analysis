┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                                 │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Every 5 minutes:                                                           │
│                                                                              │
│  1️⃣  Vercel Cron triggers /api/oracle                                      │
│                                                                              │
│  2️⃣  Oracle queries contract for AnalysisRequested events                  │
│                                                                              │
│  3️⃣  For each pending request:                                             │
│       • Fetch X/Twitter profile data                                        │
│       • Fetch last 100 tweets                                               │
│       • Calculate 3 metrics:                                                │
│         - Engagement Score (0-100)                                          │
│         - Posting Consistency (0-100)                                       │
│         - Content Risk Score (0-100)                                        │
│       • Determine Risk Level (Low/Medium/High)                              │
│       • Sign result with TEE private key                                    │
│       • Submit to contract via fulfill()                                    │
│                                                                              │
│  4️⃣  Results stored permanently on-chain                                   │
│                                                                              │
│  5️⃣  Logs recorded for monitoring                                          │
│                                                                              │
│  Repeat every 5 minutes automatically ♾️                                    │
